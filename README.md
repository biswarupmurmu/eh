# eh
> "অ্যাঁ! আরো একটা টেক্সট এডিটর?!" 
> (What?! Yet another text editor?!)

**eh** is a very simple text editor for Unix-like environments.

### How to install
- Make sure you have `gcc` and `make` installed.
- Clone this repository `git clone https://github.com/biswarupmurmu/eh.git`
- `cd` into the project `cd eh`
- Build it `make release`
- Copy the binary `build/eh` to wherever you like(to any directory in your your `PATH`)

### Usage
Open a file `eh [filename]`
Get help `eh -h`
Save file `Ctrl+s`
Exit `Ctrl+c`
